# The pictures in the README

Eleven window shots, in the order the README shows them. Each one is the whole
Words window with its shadow, scaled to 1800 points wide:

```bash
Scripts/screenshot.sh home
```

Click the window when the cursor turns into a camera. Keep the names — the
README points at them — and keep the same language pair across all eleven, so
the set reads as one session rather than eleven.

| File | What is in it |
|---|---|
| `home.png` | Home, with reviews and new words waiting, the streak, and the activity calendar filled in |
| `one-word.png` | Add Words ▸ One Word: a word typed with its article, the gender filed, an example and its translation in place |
| `anki-import.png` | Add Words ▸ From Anki: a deck's fields mapped, with the card preview beside them |
| `library.png` | Library with decks in the sidebar and a table of words — stages, audio, next review |
| `statistics.png` | Statistics: vocabulary by stage, review history, the forecast |
| `review.png` | A card turned over: meaning, example, audio, and the four ratings |
| `dictation.png` | Dictation mid-phrase: a box per word, with a marked line above it |
| `wordfall.png` | WordFall in play, with points, level and accuracy |
| `companion.png` | The companion open beside a card, mid-answer |
| `languages.png` | Settings ▸ the language pair, flag, voice and playback |
| `export.png` | Export: languages, decks and subdecks ticked, with what to include beside them |

Two things to check before replacing a file. The sidebar must show **Export**
— every shot taken before 1.1.0 is missing it, which is how the old set went
out of date. And the One Word screen is a card now, not a form.
